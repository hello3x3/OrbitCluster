# 03 使用手册（面向用户）

## 0. 访问与账号

- 浏览器打开门户（例）：`http://<ADMIN>:8000`（管理员给你的地址/账号）；
- 账号由**管理员开通**（没有自助注册）；首次用管理员给的初始密码登录；
- 登录后右上角可修改显示名、修改登录密码。

## 1. 第一次使用：完善个人资料（申请资源前必做）

「个人资料」页：

1. **SSH 登录公钥**：把自己电脑上生成的公钥整行粘贴并“添加”。
   生成（本地电脑）：
   ```bash
   ssh-keygen -t ed25519        # 一路回车；然后把 ~/.ssh/id_ed25519.pub 内容粘贴到门户
   ```
   说明：公钥会写入你集群账号的 `~/.ssh/authorized_keys`；**集群上没有同名账号时不能登记**。
   可在“用户管理”让管理员确认你的 OS 账号；若之前已有 OS 账号，门户会自动并入你现有公钥。
2. **登记 SSH 端口**：填 10000–65535 之间的端口号并“登记”。
   实时校验：过小/常用端口/别人已申请/自己已有 都会红字提示并禁用按钮；
   建议登记 2-3 个，便于同时跑多个资源。端口全门户唯一。

## 2. 申请资源

「申请资源」页（普通用户直接申请；管理员如 root 有同名 OS 账号也能自助申请）：

| 字段 | 填写说明 |
|---|---|
| 任务名称 | 必填，**3–10 个字符**；**同一用户下不能重名**（不区分大小写）。停机/取消都**不会**释放名称，需先在「我的资源」里**删除**那条记录才能复用同名 |
| 镜像 | 分两组下拉：**公共镜像**（管理员维护，`<IMAGES_MOUNT>/*.sqsh`）与**我的镜像**（你自己从运行中容器保存的，存放在 `<IMAGES_MOUNT>/<你的用户名>/`）。建议选名称带 cuda 的（内置 sshd，可交互登录）；纯数据/无 sshd 镜像可提交但无法交互 SSH |
| 套餐 | 管理员预设。注意看 GPU 型号/核数/内存与“最长时长” |
| 时长 | 默认 12 小时；**不得超过所选套餐 maxtime**（超出会置灰提交，提示找管理员代申请） |
| 节点 | 默认留空 = Slurm 自动调度（推荐）；也可以手动指定某节点 |
| SSH 端口 | 从你自己的端口池选；正在使用（排队/运行）的端口不可选 |

提交成功会提示作业号，请到「我的资源」看排队/运行。

## 3. 我的资源（状态 / 配额 / 连接 / 日志 / 停机）

- **我的配额 / 额度**（页面顶部区块，需要你集群存在同名 OS 账号才显示）：
  - **磁盘配额**：/share 已用 / 硬上限（GiB），为集群 **OS 实际值**（repquota 实读）；
  - **Slurm 关联**：账号、QoS（含优先级）、关联优先级；
  - **总额度**：Slurm QoS/关联上的资源限额（MaxTRES/GrpTRES/作业数/时长等）；当前全未设置＝**不限**；
  - 想改磁盘配额请联系管理员（管理员「用户管理 → 改配额」直接写 OS，非门户记录）。
- 每个资源（实例）显示：任务名/套餐·镜像、状态（排队中/运行中/已停止…）、节点、端口、配置、时长、申请时间；
  > 提示：从「运行中」到容器内可登录通常还需 **1–2 分钟**（提交后要先在计算节点本地展开一次镜像，
  > 再启动容器内 sshd）。若刚显示运行就 SSH 提示 Connection refused，请稍等再连。
- **运行中**点「连接/详情」得到登录命令（**直接给真实节点 IP**，复制即可）：
  ```bash
  ssh -p <端口> <用户名>@<真实节点IP>    # 例如 ssh -p 28771 alice@<ADMIN_IP>
  ```
  （申请时若未指定节点，系统运行后会自动回填实际节点名与 IP；IP 均在详情里给出，无需另找管理员索取）
  > ⚠️ **只使用门户给你的 `<端口>`（≥10000）**。同一台机器上的 2180 等端口是集群自身的
  > SSH 服务，**平台用户没有登录宿主机集群的权限**（只能用容器）。若你去连那些端口，
  > 会被服务器拒绝 —— 这是设计如此，不是故障。所有计算都请在自己的容器里做。
- 首次连接会提示 host key 变化：容器 host key 存在你家目录，删除过容器/换机器会再提示，接受即可；
- **日志**：点「日志」弹出两块内容 ——
  **容器日志**：容器内 sshd / 作业输出（应能看到 `[start_ssh] 实际监听端口` 字样）；
  **门户操作日志**：门户侧做的事，如「已提交资源」「开始保存个人镜像」「镜像已保存…；耗时 N 秒」
  「资源已到期，开始自动保存镜像后停机」「已手动停机」等，保存失败时会带上失败原因；
  作业已结束/日志被清理时容器日志可能为空，但这块记录仍在，便于回溯。
- **保存镜像**（运行中的资源）：把容器“当前状态”整体导出为**个人镜像**，落盘到
  `<IMAGES_MOUNT>/<你的用户名>/<名称>.sqsh`。填写名称时只允许**英文/数字/点/横线/下划线/加号**（1–32 位，不能以点/横线/加号开头，不含空格/路径分隔符）；
  同名镜像再次保存需点“覆盖”。导出的镜像**计入你的 /share 磁盘配额**（文件归你所有），
  配额不足会保存失败并给出提示。保存是分钟级操作（取决于容器改动量），期间该资源的停机等操作会提示
  “正在保存镜像”稍候再试；完成后资源行下方会显示保存结果。之后在「申请资源 → 我的镜像」即可再次选用；
- 资源**到期自动保存一次**：作业运行到所选时长后，门户会先把容器当前状态自动保存为
  `auto_<任务名>_<YYYYMMDD_HHMM>.sqsh`（仍在你自己的镜像目录、计入配额，每次到期都新建一个带时间戳的文件），
  然后自动停机。因此实际运行时长 = 所选时长 + 自动保存耗时（保存所需余量已含在提交给调度器的时长里）；
- **停机**：点「停机」终止容器并释放端口，之后可用同一端口重新申请；
- 对已停止/已结束/失败的资源可：
  - **重新启动**：按原参数（镜像/套餐资源/端口/时长/任务名）重新提交一次，原记录复用并回到“排队中/运行中”；
  - **删除**：删除该条资源记录，并同步清理它的作业日志文件（不可恢复）；
- 可同时申请多个资源；同一端口同时只能有一个活跃实例（同用户），不同端口可并行。

## 3.5 我的镜像（改名 / 删除）

「我的镜像」页只管**你自己的个人镜像**（`<IMAGES_MOUNT>/<你的用户名>/*.sqsh`，即你在「我的资源」里
「保存镜像」或到期自动保存得到的那些）。
**正在打包的镜像不会出现在列表里** —— 导出先把内容写成 `.part`，成功那一刻才改名成 `.sqsh`，
所以列表里出现的都是完整可用的镜像。公共镜像由管理员维护，不在本页列出/改动（它是「申请资源」时的可选项）。

| 列 | 含义 |
|---|---|
| 名称 / 大小 / 保存时间 | 文件名（`<名称>.sqsh`）、占用空间、最后修改时间 |
| 占用 | `排队中 N` / `运行中 N` = 有几个资源正在用它；`空闲` 表示没人用 |
| 注释 | 你给这个镜像写的一句话（**最多 64 个字符**，支持中文/表情/空格；连续空格会合并成一个）。该列**宽度固定**：注释按**实际渲染宽度**放得下就整段显示，放不下才在末尾显示 `…`，并在列右侧出现蓝色「**详情**」——点它弹出完整内容（与字符个数无关，中英文/表情混排一致）。点「注释」按钮可编辑，清空即删除注释 |
| 操作 | **注释**、**重命名**、**删除** |

- **注释**：「保存镜像」时起的名字往往看不出里面装了什么，注释就是为此。它**和镜像存在一起**：
  同目录的同名 JSON（`<名称>.sqsh` ↔ `<名称>.json`，例如 `torch_base.sqsh` + `torch_base.json`），
  里面还有保存人/作业号/节点/时间等信息；改名时 JSON 跟着改名，删除镜像时一并删掉。
  注释**最多 64 个字符**（中文、表情、空格都行），**只有你自己**（以及 root）看得到。
- **重命名**：名字规则同上（**英文/数字/点/横线/下划线/加号**，1–32 位，不能以点/横线/加号开头）。改名只动文件名，**配额与属主不变**；
  你历史资源记录里引用的镜像名会一并更新，所以那些「已停止」的资源仍然可以「重新启动」。
  镜像正被**排队中**的资源使用时不能改名（那时镜像还没展开到节点本地），请等它跑起来或删掉该资源。
- **删除**：不可恢复。被**排队/运行中**的资源占用时不能删（先停机并删除这些资源）；删除只影响以后，
  已经在跑的容器不受影响，但之后不能再用它「重新启动」。
- 两个操作都走门户的 root 助手（`portal-ctl rename-image` / `delete-image`），只动
  `<IMAGES_MOUNT>/<你的用户名>/` 下的普通 `.sqsh`：路径越界、软链、别人的目录一律拒绝。
- 删除会释放对应的 `/share` 配额；配额快满时，删掉不用的镜像是最快的腾空间办法。

> **root（超级管理员）在这个页面看到的是全部镜像**：公共镜像 + 所有人的个人镜像（多一列「归属」，
> 公共镜像标 `公共`）。root 可以给**任意**镜像改注释、改名、删除 —— 用户看不到别人的镜像与注释，
> 反之亦然。删掉别人正在用的镜像同样会被占用保护挡住。

## 4. 我申请超长了/要更大资源

时长受套餐 maxtime 限制。如需超过套餐上限的时长，请联系**平台管理员**，
由他在「代申请资源」里用你的账号提交（选择你的用户名与你的端口，时长不受套餐限制）。
磁盘配额不够用时同样联系管理员在「用户管理 → 改配额」扩容。

## 5. 退出与安全

- 用完记得「停机」释放资源（配额/优先级角度也更公平）；
- 私钥请勿外传、勿上传到非本人账号；忘记门户密码找管理员重置，忘记 OS/容器密码
  （一般用密钥登录，不涉及密码）；
- 你的家目录数据在 `/share/home/<用户名>`（跨节点共享），重要数据及时备份。

## 6. 常见问题

| 问题 | 解答 |
|---|---|
| 登录提示密码错误 | 找管理员重置（管理员在用户管理→重置密码，或 OS root 改密码文件） |
| 申请页说“个人资料未完善” | 去个人资料：≥1 把公钥 且 ≥1 个端口 |
| 提交按钮灰色 | 检查：任务名 3-10 字符、时长≤套餐 maxtime、端口可用 |
| 状态一直是“排队中” | GPU 被占满会排队；可去“集群状态”看空闲，或指定空闲节点重提 |
| 保存镜像失败/提示配额不足 | 保存的镜像计入你的 /share 配额：先删掉不再需要的个人镜像/家目录大文件释放空间，再重试；或联系管理员扩容 |
| 想保存镜像但按钮不在/报“容器未在运行” | 保存只在**运行中**可用：容器已结束（含到期停机后）其改动已随容器销毁，无法再保存；下回请在到期前手动保存 |
| ssh 提示 Permission denied | 私钥没带对（-i 你的私钥）；或公钥尚未生效（重新登记后 20s） |
| 刚显示“运行中”但 SSH 连不上/Connection refused | 容器先要在节点本地展开镜像（约 1-2 分钟）才会启动 sshd；等待片刻重试即可。长时间连不上再查作业日志 |
| 容器里看不到 GPU | 请确认申请的是 GPU 套餐且作业运行在 GPU 节点（容器内 nvidia-smi 应可见） |
| 端口想换/删 | 停机释放后，在个人资料删除该端口即可 |
