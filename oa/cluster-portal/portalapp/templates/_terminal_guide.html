安装终端工具

支持 macOS、Linux 和 WSL，需要 Python 3.10 或以上。使用原有平台账号登录，无需管理员权限安装。

先向管理员获取 HTTPS 服务地址。使用内部 CA 时，还需要 CA 公共证书及其本机路径；它不是 SSH 密钥。现有 HTTP 网页地址不能直接用于终端认证，服务端需先开通终端 API 与 HTTPS。

请填写 HTTPS 服务地址

输入只在当前页面生成命令，不会保存到服务器。安装器来自 OrbitCluster 仓库，使用固定发布版本，独立安装在当前用户目录，不修改系统 Python。

登录与日常使用

安装后启动，在终端输入平台用户名和密码：

~/.local/bin/orbit tui

认证默认固定有效七天，以登录后显示的到期时间为准；到期重新登录，不自动续期。退出 TUI 不会停止作业。

交给 agent 操作

先由你完成登录，再让 agent 调用命令：

orbit login --username 你的用户名
orbit instances list --json
orbit images list --json
orbit --help

找不到 orbit 时，使用 ~/.local/bin/orbit。不要把密码或本地 auth.json 发给 agent 或提交到仓库。写操作超时后，先查询结果，再决定是否重新提交。

给 Codex 安装 OrbitCluster skill

skill 告诉 agent 如何使用用户端命令；平台账号仍由你在终端登录。将下面命令复制到本机终端，安装后重启 Codex。

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills/orbitcluster"
curl -fsSL 'https://raw.githubusercontent.com/hello3x3/OrbitCluster/codex/frontend-optimization/skills/orbitcluster/SKILL.md' \
  -o "${CODEX_HOME:-$HOME/.codex}/skills/orbitcluster/SKILL.md"

接着可让 Codex“使用 $orbitcluster 查看我的资源”或按你的要求申请任务。
