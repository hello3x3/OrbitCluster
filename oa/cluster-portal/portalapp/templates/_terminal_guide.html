安装 OrbitCluster CLI

给用户和 agent 使用的命令行工具。客户端是独立程序，无需安装 Python、pip、Git 或 Go。支持 macOS、Linux、WSL 和原生 Windows，安装包只从当前门户下载。

内网 HTTP 默认可用。HTTP 明文传输密码和令牌，请在实验室可信网络中使用；认证固定七天有效，不自动续期。

安装时会显示系统检测、下载进度、SHA256 校验和安装结果。macOS/Linux 默认启动器为 ~/.local/bin/orbit；Windows 为 %LOCALAPPDATA%\OrbitCluster\bin\orbit.exe，可将对应目录加入用户 PATH。

登录与 agent 使用

先由本人登录，密码隐藏输入，不发送给 agent：

orbit login --username 你的用户名
orbit whoami
orbit plans
orbit images list
orbit instances list
orbit --help

默认结果按列表和详情整理，保留资源 ID、状态、配置、时间和异常；--details 展开额外信息，--json 获取可精确解析的完整数据。日志保留真实换行，SSH 命令可直接复制。

认证由服务器签发，固定七天，到期重新登录，不自动续期。不使用网页 Cookie。--json 成功结果写 stdout，错误写 stderr；写操作超时后先查询结果再决定是否重试。退出命令行不会停止作业。

更新与卸载

当前门户发布 CLI {{ terminal_cli_version }}。登录成功会检查新版，只提醒，不自动安装；检查失败不会影响已完成的登录。更新从本门户下载、校验并保留配置与登录，不延长认证期限。

orbit update --check   # 只检查
orbit update           # 下载并更新
orbit --version        # 确认版本

Windows 在当前命令退出后更新；其它终端占用时等待，失败日志路径会显示。旧版本没有 update 或便携文件没有安装记录时，重新运行上面的安装命令。卸载默认保留配置；需要清除本机配置和登录信息时加 --purge。这些操作不停止集群任务，不删除服务器数据。

orbit logout
orbit uninstall
# 同时清除本机配置和登录信息：
orbit uninstall --purge

orbit logout 撤销当前服务器令牌。仅删除本机登录信息不会提前撤销服务器上的令牌，其仍会在到期时失效。

给 Codex 安装 OrbitCluster skill

将 SKILL.md 放入本机 ~/.codex/skills/orbitcluster/SKILL.md（Windows 为用户目录下的 .codex\skills\orbitcluster\SKILL.md），重启 Codex。然后让 agent“使用 $orbitcluster 查看我的资源”。
