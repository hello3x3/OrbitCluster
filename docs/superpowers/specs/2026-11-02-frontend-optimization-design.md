| Toast、弹窗、状态 | 多套圆角、间距和提示颜色 | 统一控件尺度，保留所有显隐和确认逻辑 |

## 视觉方向

- **产品**：实验室成员申请计算资源、连接容器、保存环境和查看集群使用情况的工作平台。
- **性格**：沉稳、准确、耐看。
- **所属世界**：实验室仪器与计算作业台；数据、任务和状态是主角。
- **重点**：资源表的任务状态与连接信息；集群状态表中的空闲/总量关系。只使用已有数据，不新增仪表盘或虚构图表。
- **识别细节**：任务状态统一用小型指示标记加完整文字；SSH 命令与作业编号按技术内容排版，其他说明保持自然中文。

配色预览后按用户反馈确定：

| 角色 | 值 |
|---|---|
| 页面背景 | `#f5f6f7` |
| 工作表面 | `#ffffff` |
| 正文 | `#20262d` |
| 次要文字 | `#59636c` |
| 分隔线 | `#dce1e5` |
| 强调 | `#2563eb`，用于主要操作、当前导航与链接 |

成功、等待、失败仍分别使用克制的绿、琥珀、红，且始终附带状态文字。

字体使用系统中文无衬线字体（PingFang SC、Noto Sans CJK SC、Microsoft YaHei 等），不请求外部字体服务。
正文 14–15px，说明 13–14px，页标题 28–32px；常规字重 400/500，必要强调最多 600。
数据使用等宽数字，作业编号、路径和命令使用系统等宽字体。

间距基于 4px 尺度。输入、按钮圆角 6–8px，内容区约 10–12px；普通内容不用悬浮阴影，弹窗保留轻阴影。
不新增页面入场动画；保留必要交互反馈，并尊重 reduced-motion。

## 平台使用指南

新增 `/guide`，标题为“平台使用指南”。登录前后均可阅读，只展示公开操作说明，不展示账号、集群私有数据或密钥。
登录页和全局导航均提供入口。使用原 Flask/Jinja 技术栈，不引入前端框架和 Markdown 服务端解析依赖。

桌面采用章节目录与单列正文；移动端目录置顶。章节用锚点直达，不新增搜索、测验或聊天等功能。
正文初稿为 `docs/user-guide.md`，实现页面时保持同一套术语和规则。

章节：

1. 首次准备：管理员开通账号，登录、修改初始密码、登记 SSH 公钥；端口自动分配。
2. 申请与连接：任务名称、账户、镜像、套餐、时长、节点；状态、连接命令、日志。
3. 保存与结束：先保存环境再手动停机；保存结果、自动保存边界、重新启动与删除记录。
4. 镜像管理：公共与个人镜像、注释、改名、删除以及占用限制。
5. 集群、额度与资料：解释用户可以从现有各页看到什么以及常见受限原因。
6. 终端工具：安装前提、安装命令、CA 配置、登录、TUI、agent 命令和固定有效期。
7. 常见问题：无法提交、排队、SSH、公钥、磁盘空间、登录过期。

“TUI 安装”是指南内可直接定位的安装区，包含 HTTPS 地址输入、可选 CA 公共证书路径和可复制命令。
输入只在当前浏览器生成命令，不向服务器保存设置或发送凭证。页面没有服务器管理功能。
若指南通过可信 HTTPS 打开，可建议使用当前 HTTPS 基础地址；HTTP 页面不猜测 HTTPS 端口，提示向管理员获取地址。
安装命令引用已推送的终端客户端版本，发布引用集中定义，避免多处散落；不用本次尚未发布的分支作为可用安装源。
默认七天的说明不作为本地续期承诺，以服务器实际签发的到期时间为准；不新增刷新认证。

必要提示必须准确：手动停机不自动保存，重新启动使用原镜像并重新分配端口；不能承诺恢复未保存状态。
镜像保存不备份内存、运行中进程或挂载目录的数据，不把自动保存描述为永不失败的备份。
