# architecture —— 系统原理（独立页面）

一份**独立的**原理介绍页面，用来讲清这套系统“从网页申请到进入容器”的完整链路。
它**不参与** `oa/` 文档的构建，也不依赖门户或任何外部资源：一个 HTML 文件，双击就能看。

## 打开方式

```bash
# 直接打开（file:// 即可，样式与 SVG 全部内联，无外链）
xdg-open architecture/index.html

# 或者起一个静态服务（想给别人一个链接时）
cd architecture && python3 -m http.server 8099
# → http://<管理节点>:8099/
```

## 约定

- 文中路径与参数一律使用**通用占位符**：`<ADMIN>`、`<GPU01>`、`<IMAGES_MOUNT>`、`<SHARE_MOUNT>`、
  `<PORTAL_PORT>`。实际部署值可在 `provision/cluster.conf` 里替换后重新生成一份实值版本。
- 页面是纯静态的（内联 CSS + 内联 SVG + 一段十几行的目录高亮脚本），不请求任何外部资源，
  因此可以离线打开、可以直接丢进任意静态目录，也可以按需挂到门户里。
- 与 `oa/` 的关系：`oa/` 是给现场用的操作手册（怎么装、怎么用、出问题怎么办）；
  本页面只讲**原理与设计取舍**，两份内容互相独立、可以分别更新。
